# Chemistry Learning Hub

Інтерактивний навчальний простір з хімії для здобувачів освіти.

## Концепція

Chemistry Learning Hub об'єднує різні напрями навчальної роботи з хімії в одному інтерфейсі:

- Періодична система
- дослідження властивостей елементів
- тренажери
- хімічні розрахунки
- розчинність і йонні реакції
- pH та індикатори
- віртуальна лабораторія
- довідкові матеріали
- конструктор лабораторного звіту

Проєкт розвивається як статичний застосунок для GitHub Pages без обов'язкової реєстрації та без збереження персональних результатів.

## Принципи

- хімічна коректність і перевірка навчальних даних
- адаптивний інтерфейс
- світла і темна тема
- доступність з клавіатури
- модульна структура
- українська мова інтерфейсу

## Статус

Початкова версія хабу. Першим повноцінним модулем є інтерактивна Періодична система.

## Періодична система

Внутрішній розділ: `periodic-table/`. Посилання з головної сторінки ведуть до нього без переходу в інший проєкт. Шляхи до CSS, JavaScript та даних відносні й працюють у GitHub Pages під `/chemistry-learning-hub/`.

Перенесено з `learn4life-ua/periodic-table-trainer`, коміт `ec5b4d757ff761d76790d9d61a82afb903409b57`. Джерельний репозиторій не змінюється. Дані й логіка таблиці скопійовані без змін. Додані навігація хабу й спільна тема (`chemistry-hub-theme`).

Працюють: 118 елементів, картки, пошук, фільтри, скидання, швидкі дії, модель оболонок із паузою та інтерактивний довідник. Режими «Досліджуй» і «Тренажер» поки містять анонси, як у вихідному застосунку.

Для локальної перевірки запустіть `python -m http.server 8000` з батьківської теки та відкрийте `http://localhost:8000/chemistry-learning-hub/`. ES-модулі потребують HTTP-сервера.
