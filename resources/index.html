Крок за кроком

Алгоритми та пам’ятки

Короткі схеми для типових дій у хімії. Відкрий потрібну пам’ятку, пройди кроки й перевір себе на прикладі.

01 Формула йонної сполукиЯк скласти формулу за зарядами йонів
  1. Запиши формули катіона й аніона та їх заряди.
  2. Добери найменші цілі індекси, за яких сумарний позитивний заряд дорівнює сумарному негативному.
  3. Запиши індекси праворуч унизу. Індекс 1 не пишуть.
  4. Якщо багатоатомний йон повторюється кілька разів, візьми його у дужки.
ПрикладCa2+ + Cl− → CaCl2

Один Ca2+ урівноважують два Cl−.

Цей алгоритм застосовують до йонних сполук. Для молекулярних речовин склад не визначають механічно лише за зарядами.

02 Ступені окисненняЯк знайти невідоме значення
  1. У простій речовині ступінь окиснення елемента дорівнює 0.
  2. У нейтральній сполуці сума ступенів окиснення всіх атомів дорівнює 0; у багатоатомному йоні - заряду йона.
  3. У більшості сполук H має +1, O -2; F завжди -1. Для H та O пам’ятай про винятки.
  4. Підстав відомі значення й обчисли невідоме.
ПрикладH2SO4: 2(+1) + x + 4(−2) = 0

x(S) = +6.

Ступінь окиснення - формальна характеристика атома в сполуці; він не тотожний заряду атома в молекулі.

03 Хімічне рівнянняЯк правильно розставити коефіцієнти
  1. Спочатку запиши правильні формули реагентів і продуктів.
  2. Порахуй атоми кожного елемента ліворуч і праворуч.
  3. Добирай коефіцієнти перед формулами. Індекси у формулах не змінюй.
  4. Зведи коефіцієнти до найменших цілих чисел і ще раз перевір кількість атомів.
Приклад4Fe + 3O2 → 2Fe2O3

Ліворуч і праворуч: 4 атоми Fe та 6 атомів O.

Не плутай: коефіцієнт стосується всієї формули, а індекс є частиною формули речовини.

04 Електронний балансДля окисно-відновних реакцій
  1. Визнач ступені окиснення елементів до і після реакції.
  2. Знайди атоми, ступені окиснення яких змінилися.
  3. Запиши віддавання й приєднання електронів.
  4. Зрівняй кількість відданих і приєднаних електронів, а отримані множники використай для добору коефіцієнтів.
  5. Перевір усі атоми в готовому рівнянні.
ПрикладZn0 − 2e− → Zn2+
Cu2+ + 2e− → Cu0

Zn + CuSO4 → ZnSO4 + Cu.

Окисник приєднує електрони й відновлюється; відновник віддає електрони й окиснюється.

05 Скорочене йонне рівнянняЯк перейти від молекулярного запису до суті реакції
  1. Запиши й урівняй молекулярне рівняння.
  2. Сильні розчинні електроліти запиши у вигляді йонів.
  3. Не розкладай на йони осади, гази, воду та слабкі електроліти.
  4. Скороти однакові йони ліворуч і праворуч.
  5. Перевір кількість атомів і сумарний заряд обох частин.
ПрикладH+ + OH− → H2O

Для реакції HCl + NaOH → NaCl + H2O йони Na+ і Cl− є йонами-спостерігачами.

Розчинність речовин і силу електролітів потрібно враховувати до скорочення йонів.

06 Розрахункова задачаУніверсальна послідовність дій
  1. Запиши, що дано і що потрібно знайти.
  2. Переведи величини в узгоджені одиниці.
  3. Якщо задача пов’язана з реакцією, запиши й урівняй рівняння.
  4. Визнач потрібне співвідношення: n = m/M; n = V/Vm; N = nNA; c = n/V; ω = m(речовини)/m(розчину).
  5. Виконай обчислення, запиши одиниці та перевір, чи реалістичний результат.
Мініприкладm(H2O) = 36 г → n = 36/18 = 2 моль

Спочатку знайдено молярну масу, потім використано n = m/M.

У задачах за рівнянням реакції зв’язок між речовинами задають стехіометричні коефіцієнти.
